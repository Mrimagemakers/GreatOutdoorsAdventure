# Great Outdoors Adventure

A browser driving and outdoor exploration game built with Three.js. Includes an outfitter, River Valley and Snowy Mountain destinations, Xbox/PlayStation standard gamepad support, a VR lookout, and an AR tabletop scene.

## Play locally
Serve this folder with a static web server (for example `python -m http.server 8080`) and open http://localhost:8080. Internet access is required for externally hosted runtime dependencies. WebXR requires HTTPS or a trusted local origin and compatible hardware/browser.

## Controls and XR
See [CONTROLS.md](CONTROLS.md) and [XR-GUIDE.md](XR-GUIDE.md). VR/AR session lifecycle checks and desktop tabletop preview have been tested; physical headset and AR-phone validation is still pending.

## Current scope
Driving, exploration, inventory selection and camp placement are implemented. Weapon options are inventory concepts; hunting/shooting gameplay is not implemented. Some vehicle options use labeled visual stand-ins pending custom models. Destination reference images illustrate the intended look.
